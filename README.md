**Gmail Cleaner** helps you quickly clean up your Gmail inbox by grouping emails according to the **sender** or **domain**.  
Select multiple senders and delete all their emails in a single click — keeping your inbox neat and organized.

---

## 🚀 Features

- 🔍 **Group Emails** — Organize emails by sender or domain.  
- 🗑️ **Bulk Delete** — Select multiple senders and delete all their emails in one go.  
- ⚡ **Fast & Secure** — Uses the Gmail API for efficient and safe email management.  
- 💻 **Simple Interface** — Clean, intuitive frontend for smooth interaction.  

---

## 🛠️ Tech Stack

- **Frontend:** React js 
- **Backend:** Node.js / Express
- **API:** Gmail API (with OAuth 2.0 authentication)
